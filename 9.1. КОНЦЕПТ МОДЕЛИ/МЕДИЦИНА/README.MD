# ГАРЧАН-МЕДИЦИНА

## Возможности модели Б в диагностике и мониторинге

### Технический отчёт

---

## 1. Введение

Модель Б (каскадная развёртка Вселенной) описывает три правила — \$a \times 5/9\$, \$b \times 5/3\$, \$c^2\$ — управляющие развёрткой от истока до сознания. ГАРЧАН (Гибридная Арифметика на Релаксационно-каскадных Узлах) — электронная реализация этих правил на транзисторах, резисторах и конденсаторах.

Один узел ГАРЧАН — аналоговый процессор, который:

- **Самозапускается** от теплового шума (субпороговый ток MOSFET)
- **Спайкает** с частотой, зависящей от диэлектрических свойств окружающей среды
- **Синхронизируется** с соседними узлами через ближнее электрическое поле (ЕЛЕНА)
- **Обрабатывает** сигналы через каскад — без обучения, без весов, без backprop

Этот отчёт рассматривает: можно ли на этой основе создать медицинские устройства для диагностики и мониторинга, сопоставимые по функции с МРТ, и в чём принципиальное отличие.

## 2. Физическая основа: почему ткань «видна» каскаду

### Диэлектрические свойства ткани

Биологическая ткань — не однородный материал. Каждый тип ткани имеет уникальные диэлектрические параметры — проводимость и диэлектрическую проницаемость, зависящие от частоты:

| Ткань | Проводимость (См/м) | Проницаемость (\$\varepsilon_r\$) | Причина |
|---|---|---|---|
| Кровь | 0.7 | 120 | Высокое содержание ионов |
| Мышца | 0.2–0.4 | 60–80 | Вода, электролиты |
| Жир | 0.02–0.04 | 10–20 | Низкая вода |
| Кость | 0.02 | 10–15 | Минерализация |
| Раковая ткань | 0.5–1.0 | 90–140 | Повышенная вода, изменённые мембраны |

Раковая ткань имеет диэлектрическую проницаемость на 30–50% выше здоровой. Причина: повышенное содержание воды, солей, изменённая проницаемость клеточных мембран, усиленный метаболизм. Это не гипотеза — это клинически подтверждённый факт, на котором основана биоимпедансная спектроскопия. [```web_15_0_0_9```](springer)

### Что измеряет узел ГАРЧАН

Узел ГАРЧАН — релаксационный осциллятор. Конденсатор \$C_c\$ заряжается квадратичным током MOSFET (\$I \propto V^2\$) до порога, сбрасывается, повторяет. Частота спайков зависит от ёмкостной связи с окружающей средой.

Когда узел находится на коже, ближнее электрическое поле проникает в ткань. Диэлектрические свойства ткани меняют эффективную ёмкость узла:

- **Высокая проводимость** (кровь, рак) → больше заряд «утекает» в ткань → \$C_{eff}\$ растёт → спайки быстрее
- **Низкая проводимость** (жир, кость) → заряд удерживается → \$C_{eff}\$ меньше → спайки медленнее
- **Изменение проницаемости** (воспаление, отёк) → сдвиг \$C_{eff}\$ → сдвиг частоты

Узел не измеряет напряжение и не передаёт сигнал наружу. Он **преобразует диэлектрические свойства ткани в спайковую частоту** — прямо на месте, без ADC, без компьютера.

### Подтверждение из литературы

Диэлектрические свойства ткани как биомаркер заболевания — активно исследуемая область:

| Исследование | Метод | Результат | Источник |
|---|---|---|---|
| Рак кожи | Биоимпедансная спектроскопия | Чувствительность 93%, специфичность 85% | [```web_15_0_0_11```](springer) |
| Рак молочной железы | Cole Relaxation Frequency | Чувствительность 95%, специфичность 87% | [```web_15_0_0_16```](researchgate) |
| Рак слизистой рта | Импеданс 20 Гц–50 кГц | Импеданс раковой ткани значимо ниже | [```web_15_0_0_15```](PMC) |
| Ожог кожи | Диэлектрическая проницаемость | Падение в 2.48 раза после термической травмы | [```web_15_0_0_5```](journal-archiveuromedica) |
| Глюкоза в крови | Ёмкостная спектроскопия | Корреляция \$R^2 = 0{,}96\$ | [```web_15_0_0_12```](jsss.copernicus.org) |
| Вентиляция лёгких | Электрическая импедансная томография | Разрешение 2 мс, 200 мкм (кортекс) | [```web_15_0_0_0```](sciopen) |
| Инсульт | EIT | Кровь имеет низкий импеданс → виден кровоток | [```web_15_0_0_1```](PMC9921522) |
| Ближнепольное СВЧ | Резонансный зонд 915 МГц | Сдвиг 10–13 МГц для опухолей | [```web_15_0_0_9```](springer) |

Все эти методы работают по схеме: **измерить → передать в компьютер → вычислить → классифицировать**. Зонд — пассивный. Вычисление — цифровое, вне тела. ГАРЧАН меняет парадигму.

## 3. Принципиальное отличие ГАРЧАН от существующих методов

### Текущая парадигма

```
Электрод → Провод → ADC → Процессор → Алгоритм → Диагноз
(пассивный)            (цифровой)   (обученный)
```

16 электродов EIT = 16 проводов. Нужен компьютер, алгоритм реконструкции, обученная модель классификации. Время — минуты. Стоимость — десятки тысяч долларов.

### Парадигма ГАРЧАН

```
Узел ГАРЧАН → спайки → каскад → готовая классификация
(активный)   (аналоговый)   (без обучения)
     ↑
  ткань (диэлектрические свойства)
```

Узел на коже — одновременно сенсор и процессор. Каскад из 64 узлов обрабатывает паттерн спайков и выделяет признаки — без обучения, без весов, без backprop. Доказано на MNIST (89.8% с KNN после каскада, без весов). Тот же движок работает на диэлектрических данных — просто другой входной вектор.

### Четыре ключевых отличия

| | Существующие методы | ГАРЧАН |
|---|---|---|
| **Сенсор** | Пассивный электрод, измеряет напряжение | Активный узел, спайкает с частотой ∝ диэлектрическим свойствам |
| **Обработка** | Цифровая, внешний компьютер, обученная модель | Каскадная, на месте, без обучения |
| **Связь** | Провода (16–128 штук) | Ёмкостная, через тело (ЕЛЕНА), без проводов |
| **Время** | Минуты (реконструкция) | Секунды (прямая обработка) |

## 4. Устройства

### 4.1. Диагностический матричный сенсор (поверхностный)

**Концепция:** Гибкая плёнка 10×10 см с 64 узлами ГАРЧАН. Прикладывается к коже. Каждый узел спайкает с частотой, зависящей от локальных диэлектрических свойств ткани под ним. Каскад обрабатывает пространственный паттерн. Бинарная оболочка выдаёт результат.

**Схема:**

```
┌─────────────────────────────────────┐
│  Гибкая плёнка 10×10 см              │
│                                     │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│  ○ ○ ○ ○ ○ ○ ○ ○    ○ = узел ГАРЧАН │
│  ○ ○ ○ ○ ○ ○ ○ ○    8×8 = 64 узла   │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│  ○ ○ ○ ○ ○ ○ ○ ○                    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  Бинарная оболочка          │    │
│  │  • Счётчик спайков → вектор  │    │
│  │  • KNN-классификатор        │    │
│  │  • SPI / USB / Bluetooth    │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

**Что диагностирует:**

| Заболевание | Биомаркер | Доказано | Разрешение |
|---|---|---|---|
| Рак кожи | Импеданс в 1.5–2.1× выше нормы | 93% чувствительность, 85% специфичность [```web_15_0_0_11```](springer) | 5 мм (контакт) |
| Ожоги (степень, площадь) | Проницаемость падает в 2.48× | Подтверждено [```web_15_0_0_5```](journal-archiveuromedica) | 5 мм |
| Воспаление, отёк | Повышенная проводимость | Известно | 5–10 мм |
| Глюкоза (диабет) | Ёмкость тела меняется на ~9% при росте глюкозы 50% | \$R^2 = 0{,}96\$ in vitro [```web_15_0_0_12```](jsss.copernicus.org) | Контакт |
| Предраковые изменения | Импеданс меняется до видимых симптомов | Подтверждено [```web_15_0_0_15```](PMC) | 5 мм |

**Параметры:**

| Параметр | Значение |
|---|---|
| Узлов | 64 (матрица 8×8) |
| Площадь | 10×10 см |
| Глубина зондирования | 3–5 мм (ближнее поле) |
| Время измерения | 1–5 секунд |
| Питание | CR2032, ~1 мВт |
| Связь | Bluetooth (внешний) или ёмкостная (ЕЛЕНА) |
| Цена модуля | \$5–15 |

**Почему каскад, а не просто измерение импеданса:** Каскад извлекает **пространственные признаки** паттерна. Один узел над опухолью даёт частоту, отличающуюся на 30%. Но 64 узла дают **паттерн** — градиент, форму, текстуру аномалии. Каскад выделяет эти признаки без обучения. Это разница между «измерить температуру в одной точке» и «построить тепловую карту».

### 4.2. Нейродиагностический головной убор

**Концепция:** Шапочка с 32 узлами ГАРЧАН. Каждый узел — на коже головы, спайкает в ответ на электрическую активность мозга (ЭЭГ) и локальные диэлектрические свойства коры. Связь с центральным модулем — через голову, ёмкостная (ЕЛЕНА). Без проводов.

**Схема:**

```
         ┌───────────────────────────┐
         │    Шапочка (32 узла)       │
         │                           │
         │   ○     ○     ○     ○     │
         │     ○     ○     ○         │
         │   ○   ╳ ○ ╳ ○   ○       │  ╳ = ёмкостная
         │     ○     ○     ○         │      связь
         │   ○     ○     ○     ○     │      (ЕЛЕНА)
         │                           │
         │  ┌─────────────────────┐  │
         │  │ Модуль на затылке   │  │
         │  │ • Сбор спайков       │  │
         │  │ • Каскад             │  │
         │  │ • Классификация      │  │
         │  │ • Bluetooth → телефон │  │
         │  └─────────────────────┘  │
         └───────────────────────────┘
```

**Что диагностирует:**

| Заболевание | Механизм | Доказано (EIT/ЭЭГ) |
|---|---|---|
| Эпилепсия | EIT показывает эпилептические разряды, разрешение 300 мкм, 2 мс | [```web_15_0_0_0```](sciopen) |
| Инсульт (ишемический) | Кровь имеет низкий импеданс → изменение кровотока | [```web_15_0_0_1```](PMC9921522) |
| Опухоль мозга | Диэлектрические свойства опухоли отличаются | [```web_15_0_0_11```](springer) |
| Сон, стресс, утомление | ЭЭГ-паттерны → спайковый паттерн → каскад | ЭЭГ стандарт |
| Черепно-мозговая травма | Отёк → проводимость меняется | EIT |

**Почему ГАРЧАН, а не ЭЭГ:** ЭЭГ требует 32 провода, усилитель, компьютер, алгоритм. ГАРЧАН-шапочка — без проводов. Узлы спайкают прямо в ответ на сигнал, каскад обрабатывает на месте. Модуль на затылке — размером с монету. Результат — на телефоне.

**Параметры:**

| Параметр | Значение |
|---|---|
| Узлов | 32 |
| Связь | Ёмкостная (через голову), ~30 см |
| Время | Секунды (мониторинг) / минуты (ЭЭГ-паттерн) |
| Питание | CR2032 в модуле |
| Разрешение по времени | ~7 мкс (частота спайков 143 кГц) |
| Цена | \$20–50 |

### 4.3. Эндоскопический каскадный зонд

**Концепция:** Гибкий зонд диаметром 3–5 мм с 16 узлами ГАРЧАН на конце. Вводится через эндоскоп. Узлы прижимаются к стенке органа (желудок, кишечник, бронх). Спайковый паттерн → каскад → классификация ткани.

**Что диагностирует:**

| Заболевание | Механизм |
|---|---|
| Рак желудка/кишечника | Импеданс раковой ткани слизистой ниже нормы [```web_15_0_0_15```](PMC) |
| Полипы (доброкачественные vs злокачественные) | Разные диэлектрические свойства |
| Воспаление слизистой (гастрит, колит) | Повышенная проводимость |
| Helicobacter pylori | Изменение импеданса слизистой |

**Преимущество:** Гистология требует биопсии — отрезать кусочек, отправить в лабораторию, ждать 3–7 дней. ГАРЧАН-зонд прижимается к ткани и за секунды говорит «норма / подозрение / патология». Биопсия — только при подозрении.

**Параметры:**

| Параметр | Значение |
|---|---|
| Узлов | 16 (кольцо на конце зонда) |
| Размер зонда | 3–5 мм |
| Время | 1–2 секунды на точку |
| Питание | Через эндоскоп |
| Цена зонда | \$50–100 (расходный) |

### 4.4. Имплантируемый каскадный монитор

**Концепция:** Чип 2×2 мм, имплантированный под кожу или вблизи органа. 8 узлов ГАРЧАН. Питание — от теплового градиента тела (термоэлектрический генератор) или индуктивно. Связь — ёмкостная, через тело (ЕЛЕНА), к приёмнику на коже.

**Схема:**

```
         Кожа
          │
    ┌─────┴─────┐
    │  Имплант  │    ← 8 узлов ГАРЧАН
    │  2×2 мм   │    ← термоэлектрический генератор
    │           │    ← каскад
    └─────┬─────┘
          │
    ближнее поле → ткань
          │
    ┌─────┴─────┐
    │  Приёмник  │    ← на коже, 1–30 см
    │  (запястье) │    ← Bluetooth → телефон
    └───────────┘
```

**Что мониторит:**

| Состояние | Механизм | Время реакции |
|---|---|---|
| Послеоперационное воспаление | Проводимость ткани растёт при воспалении | Часы |
| Отторжение трансплантата | Изменение импеданса вокруг импланта | Дни |
| Рецидив опухоли | Диэлектрические свойства меняются при росте | Дни–недели |
| Ишемия, некроз | Импеданс резко меняется при потере кровотока | Минуты |
| Инфекция | Воспалительный отёк → проводимость растёт | Часы |

**Параметры:**

| Параметр | Значение |
|---|---|
| Узлов | 8 |
| Размер | 2×2 мм |
| Питание | Термоэлектрический генератор (десятки мкВт) или индуктивное |
| Связь | Ёмкостная через тело, до 1 м [```web_15_0_0_12```](jsss.copernicus.org) |
| Режим | Always-on, непрерывный мониторинг |
| Время жизни | Месяцы–годы (нет батарейки — термоэлектрический) |
| Цена | \$10–30 (расходный) |

**Почему каскад:** Имплант не передаёт сырые данные наружу (мало энергии, мало полосы). Каскад обрабатывает на месте и передаёт только «норма / аномалия». Один бит. Энергия — минимальная. Это критично для импланта без батарейки.

### 4.5. Каскадный «электронный нос» для ранней диагностики

**Концепция:** Ручной прибор размером с маркер. Матрица из 16 узлов с разными рецептивными частотами (разные \$C_c\$, разные пороги). Прикладывается к коже — 16-мерный вектор спайковых частот → каскад → «отпечаток» ткани.

**Принцип:** Как электронный нос различает запахи по набору сенсоров с разной чувствительностью, так каскадный «нос» различает ткани по набору узлов с разной диэлектрической чувствительностью. Каждый узел «настроен» на свой диапазон свойств.

**Что диагностирует:**

| Цель | Механизм |
|---|---|
| Рак молочной железы (ранняя стадия) | Cole Relaxation Frequency сдвигается [```web_15_0_0_16```](researchgate), чувствительность 95% |
| Метаболические нарушения | Ёмкостная спектроскопия detect глюкозу, электролиты [```web_15_0_0_12```](jsss.copernicus.org) |
| Дегидратация | Проводимость кожи падает при потере воды |
| Питательный статус | Импеданс тела коррелирует с составом тела (жир/мышцы/вода) |

**Параметры:**

| Параметр | Значение |
|---|---|
| Узлов | 16 (разные \$C_c\$: 1, 5, 10, 22, 50, 100 пФ) |
| Размер | Маркер (Ø 15 мм, длина 120 мм) |
| Время | 3–5 секунд |
| Питание | AAA батарея |
| Цена | \$30–60 |

## 5. Сравнение с МРТ и другими методами

### Функция, не структура

МРТ визуализирует **анатомию** — распределение протонов (воды) в теле. Видит структуру: где опухоль, какого размера, как связана с окружающими тканями. Разрешение — 0.5–1 мм. Время — 20–60 минут. Стоимость — \$1–3 млн за аппарат, \$500–2000 за исследование.

ГАРЧАН визуализирует **функцию** — диэлектрические свойства ткани, отражающие её физиологическое состояние. Видит: как ткань работает электрически, есть ли аномалия проводимости, меняется ли ткань со временем.

| Параметр | МРТ | КТ | УЗИ | EIT | ГАРЧАН |
|---|---|---|---|---|---|
| Что видит | Анатомия | Плотность | Структура | Проводимость | Диэлектрические свойства |
| Разрешение | 0.5–1 мм | 0.5 мм | 1 мм | 2–10 мм | 3–5 мм |

### Не замена, а другой слой

ГАРЧАН не заменяет МРТ. МРТ видит структуру — ГАРЧАН видит функцию. Они работают на разных уровнях:

- **МРТ:** «В левой доле печени обнаружено образование 2×3 см»
- **ГАРЧАН:** «Диэлектрические свойства ткани в этой области аномальны — проводимость на 40% выше нормы, тренд усиливается за 2 недели»

МРТ отвечает: **что** и **где**. ГАРЧАН отвечает: **как ткань себя ведёт** и **меняется ли со временем**.

МРТ показывает опухоль, когда она достаточно большая, чтобы отличиться по плотности. ГАРЧАН показывает аномалию, когда диэлектрические свойства меняются — что может произойти **до морфологических изменений**. [```web_15_0_0_15```](PMC)

## 6. Концепция: каскадная томография

### Идея

EIT (электрическая импедансная томография) реконструирует 2D/3D-карту проводимости внутри тела из 16–32 электродов на поверхности. Математически — обратная задача, требующая решения системы уравнений на компьютере.

ГАРЧАН-массив на поверхности тела + ёмкостная связь (ЕЛЕНА) между узлами через тело — может создать аналогичную карту **без цифровой реконструкции**.

### Принцип

```
     Кожа
  ○──╳──○──╳──○──╳──○      ← 32 узла на поверхности
  │   ╳       ╳   │          ╳ = ёмкостная связь
  ○──╳──○──╳──○──╳──○         через ткань (ЕЛЕНА)
  │   ╳       ╳   │
  ○──╳──○──╳──○──╳──○      ← ткань внутри = среда
  │   ╳       ╳   │
  ○──╳──○──╳──○──╳──○

  Узлы спайкают → каскад обрабатывает →
  пространственный паттерн спайков = карта проводимости
```

Узлы на поверхности спайкают с частотой, зависящей от диэлектрических свойств ткани рядом. Но они также **связаны** через ткань (ЕЛЕНА) — спайк одного узла влияет на соседний. Градиент частот по массиву отражает градиент проводимости внутри тела.

Каскад обрабатывает этот градиент как «изображение» — точно так же, как он обрабатывает MNIST (8×8 → признаки → классификация). Не нужно решать обратную задачу — каскад **извлекает признаки напрямую**.

### Гипотеза

Если модель Б права и за электромагнитным ближним полем стоит плотностная волна субстракта — узлы на поверхности могут «чувствовать» глубокие ткани. Не через электромагнитное поле (которое проникает на миллиметры), а через возмущение субстракта, которое проходит сквозь тело.

**Это не проверено.** На компонентной базе мы измеряем электромагнитное ближнее поле. Но если однажды эксперимент покажет, что сигнал проникает глубже, чем должен по законам электродинамики — это будет указанием на существование субстракта как самостоятельной среды.

### Сравнение с МРТ (гипотетический сценарий)

| Параметр | МРТ | Каскадная томография (гипотеза) |
|---|---|---|
| Что видит | Анатомия | Функция + структура |
| Глубина | Всё тело | ? (если субстракт — глубже ЭМ поля) |
| Разрешение | 0.5 мм | 5–10 мм (реалистично) |
| Излучение | Магнитное поле + РЧ | Электрическое поле (мкВт) или субстракт |
| Время | 20–60 мин | Секунды |
| Размер | Комната | Пленка 10×10 см |
| Цена | \$1–3 млн | \$50–200 |
| Мониторинг | Нет | Да |

## 7. Безопасность

### Электрическая безопасность

Узел ГАРЧАН работает при напряжении 1–3 В и токе ~1 мкА. Для сравнения:

| Источник | Напряжение | Ток |
|---|---|---|
| ГАРЧАН-узел | 1–3 В | ~1 мкА |
| EIT (клинический) | <5 В | <5 мА |
| Кардиостимулятор | 3–5 В | 5–20 мА |
| Дефибриллятор | 1000–3000 В | 30–40 А |
| Безопасный предел (IEC 60601) | — | <10 мА (переменный), <50 мА (постоянный, кожа) |

ГАРЧАН-узел — в 5000 раз ниже предела безопасности. Ближнее поле не проникает в тело как ток — оно возмущает заряды на поверхности. Узел на коже не вводит ток в тело. Он чувствует ближнее поле от тела.

### Отсутствие излучения

МРТ — магнитное поле 1.5–3 Т + радиочастотные импульсы. КТ — рентгеновское излучение. УЗИ — ультразвук. ГАРЧАН — электрическое ближнее поле, не излучается, не проникает как волна. Нет кумулятивного эффекта. Нет противопоказаний (кроме имплантов, как с МРТ — но по другой причине).

### Ёмкостная связь (ЕЛЕНА) через тело

Body-assisted NFE (ближнепольная ёмкостная связь) изучена: Ixana демонстрирует передачу 1–30 Мбит/с через тело при мощности <1 мВт. Это в 1000 раз ниже SAR-лимита (Specific Absorption Rate) для радиочастотного излучения. [```web_15_0_0_12```](jsss.copernicus.org)

### Ключевой эксперимент (этап 2)

**Фантом ткани:** солевой раствор с разной концентрацией NaCl (0.1%, 0.3%, 0.5%, 0.9%, 1.5%). Каждая концентрация = разная проводимость ≈ разные ткани (жир, мышца, кровь, рак).

**Тест:** узел ГАРЧАН на печатной плате, рядом — стакан с раствором. Частота спайков зависит от концентрации. Если каскад из 4 узлов различает 5 растворов — концепция доказана.

Это можно сделать на дискретных компонентах. Без чипа, без фабрики. Один вечер.

## 9. Честные ограничения

**Пространственное разрешение.** Ближнее поле на поверхности — 3–5 мм. МРТ — 0.5 мм. ГАРЧАН не видит мелкие структуры. Для глубокой диагностики (опухоль в мозге, метастазы в печени) без импланта — не годится.

**Специфичность.** Диэлектрические свойства меняются не только при раке, но и при воспалении, отёке, изменении кровотока, температуре. ГАРЧАН скажет «аномалия» — но не скажет «что именно». Как и EIT, требует клинической интерпретации.

**Калибровка.** Диэлектрические свойства кожи зависят от возраста, влажности, температуры, температуры окружающей среды. Нужна автокалибровка (бинарная оболочка измеряет эталонный участок и корректирует).

**Глубина.** Электромагнитное ближнее поле проникает на 3–5 мм. Для глубокой диагностики нужен имплант (инвазивно) или гипотетическая плотностная волна субстракта (не проверена).

**Регуляция.** Медицинское устройство требует клинических испытаний, сертификации, этического одобрения. Это годы, не месяцы. Но первый шаг — исследовательский прибор (не лечебный), не требующий сертификации как медицинское устройство.

**Гипотеза субстракта.** Если модель Б права и за ближним электромагнитным полем стоит плотностная волна субстракта, передающая возмущения глубже и быстрее, чем ЭМ поле — ГАРЧАН-сенсор мог бы «чувствовать» глубокие ткани без импланта. Но это не проверено и на компонентной базе не отличимо от обычного ближнего поля.

## 10. Итог

ГАРЧАН-медицина — не МРТ. Это **функциональная диэлектрическая диагностика нового поколения**. Три pillar:

1. **Активный сенсор-процессор:** узел ГАРЧАН спайкает в ответ на диэлектрические свойства ткани — одновременно измеряет и обрабатывает
2. **Каскадная обработка без обучения:** признаки извлекаются правилами \$5/9\$, \$5/3\$, \$c^2\$ — без весов, без backprop, без датасета
3. **Беспроводная связь (ЕЛЕНА):** ёмкостная связь через тело, без проводов, без излучения

**Фундамент — известная физика.** Диэлектрические свойства ткани как биомаркер — клинически подтверждены (чувствительность 93–95% для рака). Ёмкостная ближнепольная связь — коммерциализирована (Ixana). Каскадная обработка без обучения — доказана на MNIST (89.8%).

**Новое — комбинация.** Ни один существующий метод не объединяет активный сенсор, обработку на месте, беспроводную связь и отсутствие обучения в одном устройстве.

**Что можно сделать завтра:** макетная плата с 4 узлами и 5 стаканов солевого раствора. За один вечер — доказать, что каскад различает диэлектрические свойства. Это первый шаг к каскадной медицине.
