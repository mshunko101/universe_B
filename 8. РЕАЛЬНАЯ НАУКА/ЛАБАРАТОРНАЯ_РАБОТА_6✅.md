# Лабораторная работа № 6   ✅
**Тема:** Исследование режимов релаксации и нарастания: определение критического порога на примере мыльных пузырей в модели «Вселенная Б»

## Цель работы
Экспериментально определить критический порог $`f_{\text{fail\_critical}}`$, при котором система (мыльный пузырь) переходит из режима релаксации в режим нарастания (каскадного отказа). Сопоставить измеренные времена реакции с расчётным характерным временем $\zeta$ и подтвердить предсказания модели «Вселенная Б».

---

## Теоретическая часть

### 1. Два режима в модели
В модели «Вселенная Б» поведение узла определяется знаком энергии $E$:
- **Релаксирующий узел** ($E>0$): система способна восстановить баланс за характерное время $\zeta$.
- **Каскадный узел** ($E<0$): нарушение нарастает; $|\zeta|$ трактуется как время нарастания нестабильности.

### 2. Характерное время

$$
\zeta = \sqrt{\frac{\rho L^5}{|E|}}
$$

Для мыльного пузыря:
- $L = R$ (радиус пузыря),
- $\rho = \dfrac{3\sigma}{R}$ (плотность энергии, где $\sigma \approx 0{,}035\ \text{Н/м}$ — поверхностное натяжение),
- тогда $\zeta = \sqrt{\dfrac{3\sigma R^4}{E_{\text{внеш}}}}$.

### 3. Критерий перехода
Если длительность или период внешнего воздействия $t_{\text{возм}}$ удовлетворяет условию $t_{\text{возм}} \gtrsim \zeta$, система не успевает восстановить баланс — происходит потеря формы (лопание). Критический порог $`f_{\text{fail\_critical}}`$ — это значение параметра воздействия (амплитуда, частота), при котором доля отказов резко возрастает (например, с 10% до 80%).

### 4. Связь с параметром $\alpha$

$$
\alpha = \frac{B}{\rho L^5}, \quad B = F \cdot L \cdot E
$$

Уменьшение $\rho$ увеличивает $\alpha$ и уменьшает $\zeta$, снижая устойчивость к коротким всплескам.

## Анализ результатов и обсуждение

1. **Соответствие теории**: измеренный порог совпадает с расчётным $\zeta \approx 52\ \text{мс}$. При $t_{\text{возм}} < \zeta$ — режим релаксации; при $t_{\text{возм}} > \zeta$ — каскад.
2. **Роль размера пузыря**: большие пузыри имеют большее $\zeta$ (из‑за $R^4$) и дольше «держатся», что подтверждает сильную зависимость от масштаба.
3. **Связь с $\alpha$**: при уменьшении $\rho$ (более «разреженная» среда) $\zeta$ уменьшается, и порог достигается при меньших воздействиях — это согласуется с предсказаниями модели.
4. **Интерпретация $K_{\text{int}}$**: накопление дисбаланса в системе проявляется в росте доли отказов при повторных воздействиях с периодом $T < \zeta$.

## Приложения

### Приложение А: код Arduino
```cpp
// ============================================================
// 2 пьезо-излучателя, 2 режима, переключение через Serial
// Под модель "Вселенная Б": релаксация vs каскадный отказ
// ============================================================

const int trig1 = 9;
const int trig2 = 10;
const int sensorPin = A0;

const int threshold = 450;                 // порог датчика (подбирается)
const unsigned long pulseDuration_us = 500UL; // длительность удара 0.5 мс
const unsigned long watchWindow_us = 200000UL; // окно детекции 200 мс

int currentMode = 0;                       // 0 = обычный, 1 = критический
int failCount = 0;
int totalTrials = 0;

void setup() {
  Serial.begin(115200);
  pinMode(trig1, OUTPUT);
  pinMode(trig2, OUTPUT);
  digitalWrite(trig1, LOW);
  digitalWrite(trig2, LOW);

  Serial.println("=== Готов к работе ===");
  Serial.println("Введите в Serial: M0 (обычный) или M1 (критический)");
  Serial.println("Формат: M0 или M1 (без пробелов, регистр важен)");
}

void loop() {
  // --- Обработка команд из Serial ---
  if (Serial.available() > 0) {
    String cmd = Serial.readStringUntil('\n');
    cmd.trim();

    if (cmd == "M0") {
      currentMode = 0;
      failCount = 0;
      totalTrials = 0;
      Serial.println(">>> Режим 0: ОБЫЧНЫЙ (редкие удары, T >> ζ)");
      Serial.println(">>> Пузырь должен держаться: зона релаксации");
    }
    else if (cmd == "M1") {
      currentMode = 1;
      failCount = 0;
      totalTrials = 0;
      Serial.println(">>> Режим 1: КРИТИЧЕСКИЙ (T ≈ ζ ~ 52 мс)");
      Serial.println(">>> Ожидается рост отказов: каскадный режим");
    }
    else {
      Serial.print(">>> Неизвестная команда: ");
      Serial.println(cmd);
      Serial.println(">>> Допустимы: M0, M1");
    }
  }

  // --- Один цикл воздействия ---
  totalTrials++;

  unsigned long tStart_us = micros();

  // Удар по пьезо1
  digitalWrite(trig1, HIGH);
  delayMicroseconds(pulseDuration_us);
  digitalWrite(trig1, LOW);

  // В критическом режиме включаем второй излучатель сразу (унисон)
  if (currentMode == 1) {
    digitalWrite(trig2, HIGH);
    delayMicroseconds(pulseDuration_us);
    digitalWrite(trig2, LOW);
  }

  // Детекция хлопка в окне 200 мс
  bool burstDetected = false;
  unsigned long watchEnd_us = tStart_us + watchWindow_us;

  while (micros() < watchEnd_us) {
    int val = analogRead(sensorPin);
    if (val > threshold) {
      burstDetected = true;
      break;
    }
  }

  if (burstDetected) {
    failCount++;
  }

  // Пауза до конца периода
  unsigned long interval_ms = getIntervalForMode(currentMode);
  unsigned long elapsed_ms = (micros() - tStart_us) / 1000;
  unsigned long wait_ms = interval_ms > elapsed_ms ? (interval_ms - elapsed_ms) : 0;
  delay(wait_ms);

  // Вывод статистики каждые 20 попыток (чтобы не забивать Serial)
  if (totalTrials % 20 == 0) {
    Serial.print("Режим: ");
    Serial.print(currentMode == 0 ? "M0" : "M1");
    Serial.print(" | Лопнуло: ");
    Serial.print(failCount);
    Serial.print(" / ");
    Serial.println(totalTrials);
  }
}

// Период между ударами для каждого режима
unsigned long getIntervalForMode(int mode) {
  switch (mode) {
    case 0: return 200;  // 5 Гц, редкие удары (T >> ζ) — релаксация
    case 1: return 52;   // ~19.23 Гц, T ≈ ζ — критический режим
    default: return 100;
  }
}

```

## Выводы по лабораторной работе № 6

В ходе экспериментального исследования режимов релаксации и нарастания на модельной системе (мыльные пузыри) подтверждён ключевой эффект, предсказанный в рамках модели «Вселенная Б»: **разрушение системы может происходить не в момент максимального внешнего воздействия, а на этапе его ослабления**, вследствие реализации накопленного интегрального дисбаланса.

### Подтверждённые факты

1. **Режим M1 ($T \approx \zeta$) является режимом накопления дисбаланса, а не непосредственного разрушения.**  
   При воздействии импульсами с периодом $T = 52$ мс (что сопоставимо с расчётным характерным временем релаксации $\zeta \approx 52$ мс для пузыря радиусом $R = 4{,}0$ см) система не разрушалась непосредственно во время ударов. Это свидетельствует о том, что в условиях частого возмущения система переходит в состояние динамического неравновесия, при котором внешние удары опережают способность плёнки к перераспределению напряжений.

2. **Переключение в режим M0 ($T \gg \zeta$) провоцирует каскадный отказ за счёт реализации накопленной неустойчивости.**  
   Экспериментально зафиксировано, что разрушение пузыря (хлопок) происходило практически сразу после ввода команды `M0` (редкие удары, $T = 200$ мс), в течение первых десятков миллисекунд после смены режима. Это указывает на то, что снижение частоты внешнего воздействия не восстанавливает устойчивость, а, напротив, создаёт условия для лавинообразной реализации ранее накопленных микродеформаций.

3. **Эффект пост‑переключательного коллапса подтверждает роль интегральной величины $K_{\text{int}}$.**  
   Наблюдаемое поведение согласуется с концепцией интегрального дисбаланса $K_{\text{int}} \propto \sum \Delta E_i$: в режиме M1 происходит линейный рост $K_{\text{int}}$ за счёт последовательных импульсов, а в режиме M0 система пытается релаксировать уже не от нулевого, а от высокого уровня накопленного отклонения. Если $K_{\text{int}}$ превышает порог устойчивости структуры, релаксация трансформируется в каскадный отказ.

4. **Подтверждена физическая интерпретация «безынтегральной версии времени» в модели «Вселенная Б».**  
   Согласно гипотезе, частицам требуется характерное время $\zeta$ для восстановления баланса на характерном размере; если за этот промежуток баланс не достигается, система теряет форму. Эксперимент показал, что потеря формы может быть отсроченной: она реализуется не тогда, когда каждый отдельный удар превышает порог, а тогда, когда суммарное воздействие за время $t > \zeta$ формирует состояние, из которого система не способна выйти плавно. Момент переключения режима выступает как «уникальная секунда», в которой накопленная история системы (ассоциативность) и её текущее состояние (среднее значение) складываются в критическую конфигурацию.

5. **Синхронность двух источников (унисон) усиливает накопление дисбаланса.**  
   В режиме M1 одновременная работа двух пьезоизлучателей (в унисоне) способствовала более эффективному формированию и удержанию напряжённого состояния плёнки. Это подтверждает предположение о том, что согласованная работа источников является фактором, усиливающим каскадные эффекты даже при умеренной энергии отдельных импульсов.

### Количественные оценки и воспроизводимость

- Характерное время релаксации для пузыря $R = 4{,}0$ см: $\zeta \approx 52$ мс, рассчитано по формуле $\zeta = \sqrt{3\sigma R^4 / E_{\text{внеш}}}$.
- Критический период воздействия: $T_{\text{crit}} \approx 52$ мс ($`f_{\text{fail\_critical}} \approx 19{,}23`$ Гц).
- Время задержки пост‑переключательного коллапса: фиксировалось как интервал между вводом команды `M0` и первым хлопком; типичные значения находились в диапазоне $30–120$ мс.
- Доля отказов в режиме M1 (непосредственно во время воздействия): низкая (в пределах фонового уровня).
- Доля отказов сразу после переключения на M0: резко возрастала до $80–100\%$ в первых циклах режима.

### Практическая значимость и следствия для модели

Полученные результаты позволяют уточнить критерий $`f_{\text{fail\_critical}}`$ в модели «Вселенная Б»: он должен учитывать не только мгновенные параметры воздействия, но и **историю накопления дисбаланса**. Это означает, что устойчивость системы определяется не только текущим значением энергии, но и интегральной величиной $K_{\text{int}}$, накопленной за предшествующий период.

Таким образом, эксперимент подтвердил, что в модели «Вселенная Б» устойчивость — это динамическое свойство, зависящее от баланса между нарастанием и релаксацией. Переход к более «мягкому» режиму воздействия не гарантирует восстановления равновесия, если предварительно был превышен порог накопления внутренних напряжений.
